# 简体中文优先

面向人类阅读的文本遵守以下规则。任务分类标签值、`Status:` 字段、命令和代码等机器文本保持原样。

## 项目语言

首次使用时确定项目主要语言，写入 `docs/agents/language.md`，此后沿用。文件不存在时，以用户会话语言与界面文案推断并建议补写。语言变更时更新该文件并记录架构决策。

- 架构决策记录、任务单、规格、代理任务说明、问卷、对齐记录、交接文档等面向人类阅读的技能产物使用简体中文
- 代码注释统一使用简体中文

## CONTEXT.md 术语

在 `CONTEXT-FORMAT.md` 之上叠加以下规则：

- 规范词用项目主要语言；简体中文项目用中文词
- `_Code_` 列出该概念的代码标识符：`_Code_: order`，在代码中涉及这个概念时使用的标识符必须为这里定义的词汇
- 新术语落入 CONTEXT 的同一次编辑必须成对写规范词与 `_Code_`；先写中文词、后补代码名是反模式

示例：

```md
**订单**:
用户下单后产生的一条购买记录。
_Code_: `order`
_Avoid_: 采购单, 交易单
```

## 表达方式

使用地道、简洁的简体中文，直接把事情说清楚，避免“不是...而是...”式铺垫、刻意排比和不必要的中英混用。润色不改变事实、限定或原有要求。

工程术语优先采用自然、准确的中文说法；需要保留英文时，首次出现作简短解释，后文保持称呼一致。
