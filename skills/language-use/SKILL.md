# 语言使用

## 适用范围

- **简体中文**：与用户的对话，以及架构决策记录、任务单、规格、代理任务说明、问卷、对齐记录、交接文档等面向开发者阅读的技能产物
- **英文**：代码注释、日志、CLI 提示信息、报错信息和提交消息统一使用英文；代码标识符、命令、任务分类标签值、`Status:` 字段等机器文本保持原样

## 项目领域术语

维护 `domain-modeling` 管理的项目领域词汇表 `GLOSSARY.md` 时，先读取该技能目录中的 `GLOSSARY-FORMAT.md`，再应用以下补充规则：

- 规范词使用简体中文
- `_Code_` 列出该概念的代码标识符：`_Code_: order`，在代码中涉及这个概念时使用的标识符必须为这里定义的词汇
- 新增术语时，在同一次编辑中写入规范词和对应的 `_Code_`

示例：

```md
**订单**:
用户下单后产生的一条购买记录。
_Code_: `order`
_Avoid_: 采购单, 交易单
```

## 表达方式

使用地道、简洁的简体中文，直接把事情说清楚，避免“不是...而是...”式铺垫、刻意排比和不必要的中英混用。润色不改变事实、限定或原有要求。

工程术语优先采用自然、准确的中文说法；需要保留英文时，首次出现作简短解释，后文保持称呼一致。
