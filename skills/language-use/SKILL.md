# 语言使用

## 适用范围

- **简体中文**：与用户的对话，以及架构决策记录、任务单、规格、代理任务说明、问卷、对齐记录、交接文档等供开发者阅读的技能产物。
- **英文**：代码注释、日志、CLI 提示、报错信息、测试描述和提交消息。
- **保持原样**：代码标识符、命令、任务分类标签值、`Status:` 字段等机器文本。

## 项目领域术语

维护 `domain-modeling` 管理的项目领域词汇表 `GLOSSARY.md` 时，先读取该技能目录中的 `GLOSSARY-FORMAT.md`，再应用以下补充规则：

- 规范词使用简体中文。
- 在 `_Code_` 中列出概念对应的代码标识符，如下例中的 `order`。代码中表示该概念的标识符必须使用这里定义的词汇。
- 新增术语时，在同一次编辑中写入规范词和对应的 `_Code_`。

示例：

```md
**订单**:
用户下单后产生的一条购买记录。
_Code_: `order`
_Avoid_: 采购单, 交易单
```
