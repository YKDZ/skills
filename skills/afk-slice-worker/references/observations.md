# 观察账本契约

只在设计或实现依赖可复验的环境事实或原型观察时读取。观察产物固定放在 `docs/observations/`；不要把进程内普通单元行为、会话流水、审查意见或尚未经过人类选择的界面偏好写成 OBS。

## 写入规则

- 路径：`docs/observations/NNNN-slug.md`
- 标识：`OBS-NNNN`，一条一事
- 只有能用复验命令判真假的环境事实，或有明确问题、判定阈值和结果的 `logic`/`ui-feasibility` 原型观察入账
- 先搜索相关条目，只读取与当前假设相关的文件，不加载整个目录
- 被推翻时新增条目，并在旧条目标注“被哪个 OBS 取代”；不删除历史事实
- 遵循项目现有 Git 跟踪策略，不强行加入被忽略文件；在完成报告中说明文件是否被跟踪

## 条目字段

```text
OBS-ID / 类型：environment|prototype / 一句话事实 / 观察时间 / 最近复验时间 /
环境指纹（平台、版本、工具链、关键配置） /
问题或假设 / 判定阈值 / 复验命令 / 实际观察 / 证据指针 /
写入者 / 取代哪个 OBS | 被哪个 OBS 取代
```

复验失败时，不继续依赖旧事实；报告设计或实现中受影响的假设与合同条目。
