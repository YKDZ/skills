# 观察账本契约

只在设计或实现确实依赖环境事实时读取。观察产物固定放在 `docs/observations/`；不要把进程内可测试行为、会话流水或 reviewer 意见写成 OBS。

## 写入规则

- 路径：`docs/observations/NNNN-slug.md`
- 标识：`OBS-NNNN`，一条一事
- 只有能用复验命令判真假的环境事实入账
- 先搜索相关条目，只读取与当前假设相关的文件，不加载整个目录
- 被推翻时新增条目，并在旧条目标注 `superseded-by`；不删除历史事实
- 遵循项目现有 Git 跟踪策略，不强行加入被忽略文件；在完成报告中说明文件是否被跟踪

## 条目字段

```text
OBS-ID / 一句话事实 / observed-at / last-verified-at /
环境指纹（平台、版本、工具链、关键配置） /
复验命令 / 预期观察 / 证据指针 / 写入者 / supersedes|superseded-by
```

复验失败时，不继续依赖旧事实；报告设计或实现中受影响的假设与合同条目。
