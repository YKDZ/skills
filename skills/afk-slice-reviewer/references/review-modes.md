# 条件审查模式

只在派发消息要求失败模式审查或关闭复核时读取。共同的问题项判定仍以审查者主技能为准。

## failure

只用于 C 类候选。读取已接受设计，检查候选是否保持其中的所有权、状态转移、接口与数据契约、不变量和恢复语义。只追踪当前范围可达的崩溃、并发、重入、重试、权限和外部依赖路径，不为未来扩展创建义务。

## closure

只核验已接受的必修问题、受影响合同和修复增量：

1. 复验原反例及关闭证据
2. 重证受影响合同
3. 检查修复是否新引入合同或不变量违例

保持上述焦点。原问题仍可复现，或修复新引入可证明的合同或不变量违例时，返回 `CHANGES_REQUIRED`。
