# 软时间检查点

只在用户、项目权威策略或宿主策略给出时间阈值，且宿主能可靠计量时读取。本技能不提供默认分钟数，也不建立总任务硬截止。

派发消息必须写明阈值来源、计量指标、数值秒和计量方式。未满足启用条件时不要设置检查点，也不要要求代理填写空值。

到达检查点时：

1. 不再开启新的探索分支
2. 完成或安全中止当前原子动作
3. 保存工作区，并收敛当前运行创建的临时资源
4. 交回已形成证据和未决合同条目，结束本次运行

在运行记录中写入 `CHECKPOINT`。合同未完成时行动报告 `INCOMPLETE`，目标保持进行中并保留继续资格。时间、排队和成本由宿主按能力记录；代理不估算。
