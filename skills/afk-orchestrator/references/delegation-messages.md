# 子代理消息构造参考

只读取当前要派发的模式。所有新切片和审查者都使用宿主可用的隔离上下文机制：不注入主会话历史，不继承其他代理的结论，只传递自包含任务契约、路径和提交指针。具体工具与参数由宿主决定。

## 公共派发字段

每条消息必须让接收者无需继承主会话就能定位：

- 可观察结果、风险路由、模型档位与有效执行时间护栏
- 任务单、规格、架构决策记录、设计文档、代码入口、相关 OBS 和前置提交；冲突时的权威顺序
- 阶段固定点、不可变候选提交、工作树与可写范围
- 验收合同、生产接缝、因果反例、针对性门禁和范围外工作
- 升级或停止条件，以及 `READY_FOR_ACCEPTANCE` / `READY_FOR_HUMAN` / `INCOMPLETE` 完成协议

不得复制完整文档、转述完整历史或把上一位代理的结论当成事实。

## 持久任务机制

宿主提供持久任务机制，并且切片预计跨多个会话轮次、包含多项完成证据、能在当前权限内持续推进时，才要求使用该机制：

```text
使用宿主提供的持久任务机制跟踪本消息定义的有界结果。目标覆盖可观察结果、范围和完成条件，不得缩成当轮问题项；完成证据形成前保持进行中。用量预算只在用户明确要求且宿主支持时设置。
```

宿主不提供该机制、单轮工作或可能立即等待外部输入时直接省略。持久任务完成只表示候选证据已提交，不代表编排者已经验收。

## A/B/C 实施切片

派发约束：

```text
上下文：使用宿主的隔离机制，不继承主会话历史或前序结论
模型档位：<A=t0；B/C 实施=t1>
运行配置：由项目 AGENTS.md 解析
```

消息模板：

```text
调用 afk-slice-worker 实现 <任务单> 的纵向切片：<可观察结果>。

原始依据：<任务单 / 规格 / 架构决策记录 / 已接受设计 / 前置提交 / 代码入口 / 相关 OBS 指针>。冲突时以 <权威来源> 为准。
阶段固定点：<提交>。可写范围：<文件或模块>。
风险路由：<A/B/C>。有效执行时间护栏：<时长>。
生产边界：<真实进程、权限、认证、候选产物、发布产物或外部系统>。
保持：<不变量>。范围外：<相邻工作>。
验收合同：<ID / 权威来源 / 要求或不变量 / 生产接缝或反例>。

<B 类必填机制简案：选定机制；所有权/状态或接口；关键失败模式；测试接缝；假设与相关 OBS。A/C 删除此段。>

优先建立一个在阶段固定点上因 <缺失机制> 而失败的因果证据，再完成最小实现。
当前切片运行：<针对性门禁>。完整根门禁和独立审查不属于本切片。
若出现 <具体升级条件>、达到护栏或需要越过可写范围，停止扩张并报告 INCOMPLETE。
只有验收合同全部获得证据才报告 READY_FOR_ACCEPTANCE。
```

实施持久状态机、恢复协议或可重入跨进程生命周期时，合同列出范围内状态与可中断转换，并指定生产接口发生“崩溃 → 重启”时的恢复、拒绝或重复进入证据。

## C 设计切片

设计按共享机制聚类，不按任务单复制。派发约束：

```text
上下文：使用宿主的隔离机制，不继承主会话历史或前序结论
模型档位：t2
运行配置：由项目 AGENTS.md 解析
```

消息模板：

```text
调用 afk-slice-worker 完成设计切片：为 <机制与任务单集合> 产出可实施的机制设计文档。

原始依据：<任务单 / 规格 / 架构决策记录 / 研究笔记 / 代码入口 / 相关 OBS>。冲突时以 <权威来源> 为准。
固定点：<提交>。可写范围：<设计文档路径> 与 docs/observations/。
有效执行时间护栏：<默认 60 分钟>。
必须关闭：选定机制；所有权；状态转移；接口与数据契约；关键失败模式与恢复语义；不变量；生产测试接缝；假设与证据；拒绝方案；非目标。
原型许可：<不允许 | 允许一个>。
若允许：类型 <logic | ui-feasibility | ui-visual-options>；不确定性范围 <范围>；有效执行时间预算 <明确时长>。
隔离：从固定点创建 <一次性工作树> 与 <一次性分支>；不得在阶段或实施工作树中制作原型。
临时资源：<文件、数据库、进程、端口与任务运行器入口>。
保留模式：<ephemeral | reviewable>；清理负责人：<代理/角色>；清理触发条件：<获得结论 | 人类完成选择>。

调用 `prototype` skill 前先写原型契约：
- `logic`/`ui-feasibility`：单一可证伪假设；静态证据为何不足；反证观察与判定阈值；将解锁的设计决策。
- `ui-visual-options`：明确授权来源；需要人类回答的选择问题；候选范围；运行和比较指引。不得定义代理自动选择获选方案的规则。
- 两类都写允许操作、可写范围、预算、停止条件、保留模式与结果归宿。

获得决定性观察、达到预算或越过范围时立即停止。`logic`/`ui-feasibility` 的结论与复验命令写入 `docs/observations/` 并回填设计决策；`ephemeral` 原型随后完成清理，清理前后证据纳入报告。结果不确定、需要第二个原型或清理失败时报告 INCOMPLETE。
`ui-visual-options` 完成后保留 `reviewable` 原型，报告 READY_FOR_HUMAN；不得选择、组合或折入产品。人类决策写回设计后再派清理切片，清理完成才可继续实施。
不为规格没有的需求设计。未关闭的问题必须显式列出；会迫使实施者发明生产语义的问题未关闭时报告 INCOMPLETE。
```

设计被编排者接受后，C 实施消息引用同一文档，不复制内容。

### 界面原型的人类交接

`READY_FOR_HUMAN` 必须提供：选择问题、各方案的意图区别、启动命令与 URL、固定点、一次性分支和工作树、已停止的后台资源、需要人类给出的最小答案，以及完成选择后的清理动作。编排者暂停后续派发。

恢复时把人类决定及理由写回权威设计，不直接提升原型代码。清理切片只处理已登记的一次性工作树和分支、临时文件、数据库、进程和端口；发现来源不明的修改时停止并报告 `INCOMPLETE`，不得强制删除。清理证据收敛后才派正式实现。

清理消息使用：

```text
调用 afk-slice-worker 清理原型 <PROTOTYPE-ID> 并回填人类设计决定。
原型生命周期记录：<基线 / 工作树 / 分支 / 临时资源 / 清理负责人与触发条件>。
人类决定：<选择与理由>。权威设计文档：<路径>。
允许删除：<仅列当前原型创建的精确目标>。阶段工作树清理前状态：<证据>。
停止并报告 INCOMPLETE：目标与记录不符、存在来源不明的修改/提交、无法确认资源所有权或需要强制删除。
完成证据：设计决定已回填；登记资源已清理；阶段工作树前后状态除设计与允许 OBS 外一致。
```

## 初审

先物化不可变候选。B 派一个 `contract` 审查者；C 分别派 `contract` 与 `failure` 审查者，可并行。每个审查者都使用彼此隔离、且不继承实现上下文的新上下文。

```text
调用 afk-slice-reviewer，以 <contract|failure> 模式只读审查 <候选提交>。
阶段固定点：<基线>。候选提交：<候选>。不得审查工作树浮动状态。
权威依据：<任务单 / 规格 / 架构决策记录 / 设计文档>。
验收合同：<合同指针>。生产边界：<接缝>。范围：<允许差异与明确排除项>。
现有证据：<测试、日志、产物指针>。有效执行时间护栏：<默认 45 分钟>。
只报告满足 afk-slice-reviewer 定义的 BLOCKER；其他意见标记 NONBLOCKING，不得要求零问题项。
```

模型档位：

- B `contract`：t1
- C `contract`：t1
- C `failure`：t2

## 返工与关闭复核

返工仍使用当前实施路由的档位；风险没有新证据时不升档。

```text
调用 afk-slice-worker 返工 <范围>。
返工前固定点：<提交>。原始依据：<指针>。
父级验收合同：<合同及受影响条目>。
需要关闭：<已接受的 BLOCKER ID、事实、合同关联、因果反例>。
可写范围：<范围>。保持：<不变量与非目标>。有效执行时间护栏：<剩余预算>。
逐项复现并完成最小修复；重证受影响合同，运行 <针对性门禁>。
若 `BLOCKER` 推翻设计假设或共享机制，停止窄返工并报告 DESIGN_EVENT/INCOMPLETE。
```

返工候选物化后，新开隔离上下文的 t1 审查者，只做 `closure` 关闭复核：

```text
调用 afk-slice-reviewer，以 closure 模式核验返工。
原候选：<基线>。返工候选：<候选>。
只核验：<已接受的 BLOCKER>、<受影响合同>、返工增量的合同/不变量回归。
关闭证据：<回归测试与生产边界证据>。有效执行时间护栏：<默认 45 分钟>。
不要重新进行开放式审查或代码味搜索。
```

## 继续同一实现会话

只有仍在同一原子目标且下一项证据增量明确时续派：

```text
继续当前切片，只处理 <一个缺口>。
当前可复现事实：<证据>。不要重复：<已完成探索>。
预期证据增量：<新变更、新 RED/GREEN 或待排除假设>。
剩余有效执行时间护栏：<时长>。范围与完成协议不变。
```

达到该路由的续派上限或再次没有证据增量时，记录检查点并停止该会话。
